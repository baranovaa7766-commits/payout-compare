# Техническое задание: Сайт сравнения способов вывода выплат для трейдеров

## 1. Идея продукта

Сайт-агрегатор, который помогает трейдерам (в первую очередь — трейдерам пропфирм) понять, каким способом выгоднее всего вывести и сконвертировать свою выплату в локальную валюту. Монетизация — партнёрские комиссии от платёжных сервисов (Wise, Revolut и т.д.), а не собственная обработка платежей.

**Ключевая ценность для пользователя:** прозрачное сравнение реальной суммы "на руки" по разным методам вывода, с учётом курса, комиссии и скорости — без необходимости самому искать эту информацию по разным источникам.

## 2. Целевая аудитория

Трейдеры пропфирм (FTMO, FundedNext, The5ers, E8 Markets и др.), которые получают выплаты в USD/EUR и хотят понять, как выгоднее вывести деньги в свою локальную валюту.

## 3. Структура сайта (MVP)

### 3.1 Главная страница — калькулятор

Пользователь вводит:
- Сумму выплаты
- Валюту фандинга (USD/EUR/GBP — выбор из списка)
- Локальную валюту получателя (выбор из списка)
- (опционально) страну проживания — влияет на доступность методов

Результат — таблица сравнения методов вывода:

| Метод | Курс конвертации | Комиссия | Скорость | Итого на руки |
|---|---|---|---|---|
| Wise | mid-market + наценка | известная, прозрачная | 1-2 дня | расчётное значение |
| Revolut | зависит от плана | известная | часы-1 день | расчётное значение |
| Банковский перевод | обычно хуже курс | $15-45 фикс | 3-7 дней | расчётное значение |
| Крипто (USDT) | рыночный + сеть | сетевая комиссия | минуты-часы | расчётное значение |

Каждая строка со ссылкой на партнёра — партнёрская ссылка (плейсхолдер до одобрения в партнёрках, обычный ссылка на сервис — после).

### 3.2 Страницы по пропфирмам (SEO + контент)

Отдельная страница на каждую пропфирму: "Как вывести деньги с [Фирма]" — с их конкретными методами выплат, комиссиями, минимальными суммами, встроенным калькулятором, настроенным под эту фирму.

Стартовый список фирм (данные ниже, в разделе 5).

### 3.3 Общая сравнительная статья

"Wise vs Revolut vs банк vs крипто для трейдеров" — объясняющая логику выбора метода, независимо от конкретной пропфирмы.

### 3.4 Страница Disclosure

Обязательная страница с раскрытием партнёрской монетизации (текст — раздел 6).

## 4. Технические требования

- Простой сайт (Next.js или чистый HTML/JS — на усмотрение Claude Code, оптимизируй под скорость разработки для соло-разработчика без опыта)
- Курсы валют — через бесплатный API (например Frankfurter API: https://www.frankfurter.app/, или exchangerate-api.com) для базового mid-market курса
- Данные о комиссиях/методах пропфирм — статичные данные (JSON/база), обновляемые вручную (см. раздел 5) — НЕ через API, эта информация не агрегируется автоматически
- Партнёрские ссылки — вынести в конфиг, чтобы было легко подставить реальные ID после одобрения в партнёрках
- Адаптивная вёрстка (мобильные пользователи — значительная часть аудитории)
- SEO: чистые URL по типу /payout/ftmo, /payout/fundednext, мета-теги, заголовки под целевые запросы ("how to withdraw from FTMO", "FTMO payout methods" и т.д.)
